# Field Brain 로컬 실행판

Python 3.12와 app/requirements.txt의 의존성을 사용합니다. 설치 및 데모 실행 명령은 [루트 README](../README.md)를 참고하세요.

Windows에서는 Python 설치 후 `Field Brain 데모 실행.bat` 또는 `Field Brain 실행.bat`을 사용할 수 있습니다. 처음 실행할 때 로컬 가상 환경과 의존성을 설치합니다. 이미 환경이 있다면 의존성 변경 시 requirements.txt를 다시 설치해야 합니다.

## 현재 동작

- 자유 일지와 원문 보존, 현장별 타임라인
- 작업 일정과 견적 방문 달력, 일정 변경·취소
- TXT와 Markdown 대조 기반 일정 가져오기
- 제한된 명확한 지급 문장을 실제 지출로 기록
- 수주금액·실제 비용·예상 비용을 구분하는 장부
- 현장 용어·단가 참고, 날짜별 작업자 일당
- 내부 정정·근거·감사 이력 및 DB 백업 기반

주 메뉴는 오늘·일정·현장·기록·사업입니다. 과거 검토 경로는 호환용으로 남아 있으며 일부 후보 처리에 아직 사용됩니다.

## 현재 한계

다중 현장 문맥 연결, 메이드와 견적 버전 연결, GPT 호출, 음성 전사·사진 분석, 원본 포함 통합 복원 흐름은 미완성입니다. 규칙 추출은 모든 자유 문장을 이해하지 못합니다.

수주금액은 입금액과 다릅니다. 작업 중 수주금액에서 현재 지출을 뺀 값은 최종 수익이 아닙니다. 중개수수료와 미수금 추적은 현재 제품 범위에서 제외합니다.

## 저장과 설정

- Windows 기본 경로: LOCALAPPDATA/FieldBrain
- 기타 환경 기본 경로: 사용자 홈의 .local/share/field-brain
- FIELD_BRAIN_DATA_DIR: 로컬 데이터 위치
- FIELD_BRAIN_DEMO=1: 별도 데모 데이터 사용
- FIELD_BRAIN_PORT: 기본 8765
- 데이터베이스 구조: 버전 9, 실행 시 마이그레이션 적용

실제 데이터 폴더는 저장소 밖에 두세요. 상세 제품 방향은 [Product](../docs/public/PRODUCT.md)를 따릅니다.

# Field Brain

현장의 대화와 작업 기록을 기억하고, 일정·견적·지출 판단에 연결하는 로컬 우선 업무 앱입니다. 철거 사업을 첫 실전 사례로 개발하고 있습니다.

현재는 개발 중인 MVP입니다. 자유 일지, 작업·견적 방문 일정, 현장별 기록, 지출 장부, 현장 참고와 작업자 일당을 제공합니다. 일부 명확한 문장은 규칙으로 처리하지만, GPT의 전체 문맥 분석·통화 전사·사진 분석·다중 기기 동기화는 아직 구현되지 않았습니다.

## 제품 방향

자료 전달 → 현장 연결 → 방문·견적 → 수주 → 작업·지출 → 완료 → 다음 견적에 재사용.

- [기여 안내](CONTRIBUTING.md)

## 실행 (Windows / Python 3.12)

처음에는 허구 데이터가 들어 있는 데모를 권장합니다. 저장소 루트에서 PowerShell로 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r app/requirements.txt
$env:FIELD_BRAIN_DEMO = "1"
.\.venv\Scripts\python.exe app/run.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 실제 업무 모드는 FIELD_BRAIN_DEMO를 0으로 설정하고 다시 실행합니다. 데모와 실제 업무 데이터는 별도 저장됩니다.

## 검증

```powershell
Set-Location app
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 데이터와 공개 범위

소스 코드 공개와 실제 업무 데이터 공개는 별개입니다. 기본 데이터 위치는 Windows의 LOCALAPPDATA/FieldBrain이며, 코드 저장소에 업무 DB·원본 대화·녹음·사진·인증정보를 포함하지 않습니다. 기본 실행은 로컬 주소에 한정되며, 이 저장소는 공개 웹 서비스 배포 구성이 아닙니다.

테스트는 가상 입력으로 실행합니다. 과거 개인 자료와 이관 스크립트는 공개본에 포함하지 않습니다. 첫 개발 버전으로, 실제 업무 전체 흐름의 완성이나 회계상 순이익 계산을 보장하는 제품이 아닙니다.

## 개발 순서

1. 단일 자료와 자유 일지를 현장에 연결
2. 방문 결과에서 수주와 작업까지 연결
3. 작업 변화·남은 일·실제 지출로 현장 상황 갱신
4. 완료한 경험을 다음 견적에 재사용

독립적인 세부 기능보다 위 흐름을 먼저 완성합니다.

## 라이선스

현재 저장소에는 별도의 오픈소스 라이선스를 부여하지 않았습니다. 공개 열람과 코드 재배포·상업적 재사용 허용은 별개이며, 사용 허용 범위는 라이선스 결정 후 명시할 예정입니다. 의존성에는 각 프로젝트의 라이선스가 적용됩니다.
